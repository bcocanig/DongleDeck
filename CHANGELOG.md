# Changelog

## 0.4.0 — 2026-10-30

First public DongleDeck release, following local Receiver Pairing prototypes.

- Dark and light themes with a remembered preference.
- Supplied bracket-and-USB identity, theme logos, and multi-size Windows icon.
- Continuous automatic pairing for keyboards and mice, with a manual selection option.
- Animated radio indicator, green Start pairing, red Stop pairing, and explicit continuous-scan instructions.
- Animated operation progress and elapsed time while saving or verifying a device.
- Immediate removal and clear actions with verified readback and refreshed device lists.
- Active / Seen / Inactive device observations and battery when available.
- Dell Universal Receiver 413C:301C support, physically tested on revision 0244 with KB740 and MS5320W.
- Portable Windows x64 package, original source under MIT, build/test workflow, protocol notes, and practical feature backlog.

No system-tray status states or Logitech support are included.
