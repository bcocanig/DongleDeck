# Acknowledgements

DongleDeck's Windows implementation is original code, licensed under MIT.

The USB command investigation started with Michael Knap's [dell-rf](https://github.com/michaelknap/dell-rf) and its [PROTOCOL-4503.md](https://github.com/michaelknap/dell-rf/blob/main/docs/PROTOCOL-4503.md), published under the MIT License. Those notes describe a different Dell receiver USB ID, 413C:4503; DongleDeck's initial supported device is 413C:301C, revision 0244, tested separately with physical devices. Credit for the previously documented discovery and pairing commands belongs to that project and its contributors. DongleDeck does not bundle dell-rf's program or Dell software.

No Dell DLLs, decompiled Dell source, third-party USB drivers, or Logitech software are included. Windows and .NET Framework are system prerequisites supplied by Microsoft.

Dell, Logitech, and product names identify compatible or planned hardware. DongleDeck is an independent project, unaffiliated with those companies.
